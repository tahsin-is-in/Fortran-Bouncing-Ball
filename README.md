# Fortran Bouncing Ball

A simple animated bouncing ball simulation built using GNU Fortran.

## Features
- Animated bouncing ball
- Console-based graphics
- Boundary collision detection

## Requirements
- GNU Fortran (gfortran)
- Windows

## How to Run

Compile:

```bash
gfortran main.f90 -o bouncing_ball.exe
```

Run:

```bash
bouncing_ball.exe
```
